applyBuoyancyImpulse

fun applyBuoyancyImpulse(surfacePosition: Vec3, surfaceNormal: Vec3, buoyancy: Float, linearDrag: Float, angularDrag: Float, fluidVelocity: Vec3, gravity: Vec3, deltaTime: Float): Boolean

Applies an impulse to the body that simulates fluid buoyancy and drag. If you want the body to wake up when it is sleeping, use BodyInterface::ApplyBuoyancyImpulse instead.

Return

true if an impulse was applied, false if the body was not in the fluid

Parameters

surfacePosition

Position of the fluid surface in world space

surfaceNormal

Normal of the fluid surface (should point up)

buoyancy

The buoyancy factor for the body. 1 = neutral body, < 1 sinks, > 1 floats. Note that we don't use the fluid density since it is harder to configure than a simple number between \[0, 2\]

linearDrag

Linear drag factor that slows down the body when in the fluid (approx. 0.5)

angularDrag

Angular drag factor that slows down rotation when the body is in the fluid (approx. 0.01)

fluidVelocity

The average velocity of the fluid (in m/s) in which the body resides

gravity

The gravity vector (pointing down)

deltaTime

Delta time of the next simulation step (in s)
